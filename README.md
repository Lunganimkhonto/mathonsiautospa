# Mathonsiautospa & Entertainment

A demo static website built for Mathonsiautospa with light/dark mode and a local preview setup.

## Preview locally

Option 1: Use Python

```sh
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

Option 2: Use npm

Install dependencies once:

```sh
npm install
```

Then preview locally:

```sh
npm run start
```

Or use the direct http-server preview:

```sh
npm run preview
```

## Files

- `index.html` — main website markup
- `styles.css` — theme-aware styling and responsive layout
- `script.js` — theme toggle and demo booking form logic
